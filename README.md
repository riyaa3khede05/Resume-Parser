# AI Resume Parser

## Overview
AI Resume Parser is a Flask-based web application that allows users to upload a resume in PDF format and extracts the text automatically.

## Features
- Upload PDF Resume
- Extract Resume Text
- Simple and User-Friendly Interface
- Built with Flask and Python

## Technologies Used
- Python
- Flask
- pdfplumber
- HTML

## Project Structure
```
ResumeParser/
│
├── app.py
├── templates/
│   └── index.html
├── uploads/
└── .gitignore
```

## How to Run

Install dependencies

```
pip install flask pdfplumber
```

Run

```
python app.py
```

Open

```
http://127.0.0.1:5000
```
